# 跨能力 LoRA 合并：新学的能力会被"平均掉"

> 机器 `pingji-MS-7B89` · RTX 5060 Ti 16 GB · 2026-11-27
> 任务 A：三位×两位（GRPO LoRA，60%）· 任务 B：数字→中文大写（新训 LoRA）

`lora-merging.md` 的结论是"同任务合并只是插值"。
这一轮验证另一半假设：

> **合并不同能力的两个 LoRA，能不能同时保留两者？**

答案：**不能。而且新学的能力比原生能力脆弱得多。**

---

## 1. 设置

| 项 | 值 |
| --- | --- |
| 基座 | Qwen3-1.7B（bf16） |
| LoRA A | GRPO 300 步 → 三位×两位（60%） |
| **LoRA B** | **新训**：数字 → 中文大写（3000 条，2 epoch，loss→0.000） |
| 合并 | `θ = α·A + (1−α)·B`，α ∈ {0.75, 0.5, 0.25} |
| 评测 | 每任务 200 题，贪心；B 取首行比较 |

> 任务 B 是**全新能力**：基座对它接近 0%。
> 任务 A 则有一部分来自基座（见下）。

---

## 2. 结果

| 模型 | 数学（A） | 中文大写（B） |
| --- | ---: | ---: |
| 只有 A | **60.0%** | 0.0% |
| 只有 B | **50.0%** | **86.5%** |
| 合并 α=0.75（B 占 25%） | 57.0% | **0.0%** |
| 合并 α=0.50（B 占 50%） | 52.5% | **0.0%** |
| 合并 α=0.25（B 占 75%） | 51.5% | **85.0%** |

### 2.1 三个反直觉

1. **只装 B 的模型，数学还有 50%**——说明数学能力**大部分在基座里**，A 只加了 10 pp；
2. **B 的权重降到 50%，中文大写直接归零**——不是渐变，是**悬崖**；
3. **合并后数学退化很温和**（60 → 57 → 52.5 → 51.5），因为它是"基座能力 + 小幅修正"。

---

## 3. 为什么：新行为 vs 增强

| 能力类型 | 来源 | 合并时的表现 |
| --- | --- | --- |
| **新行为**（B：输出中文大写） | 几乎 100% 来自 LoRA | 权重一摊薄就失效 |
| **增强**（A：数学 +10 pp） | 基座 50% + LoRA 10% | 摊薄后退回基座水平 |

新行为依赖 LoRA 提供的**持续偏置**：每一层都要把输出往"中文大写"方向推。
按 0.5 平均后，这个偏置只剩一半，**过不了改变输出格式的阈值**，于是输出回到基座的默认行为（`<answer>` 风格），整题判 0。

> 所以"合并"平均掉的是**偏置的幅度**，而输出格式是**阶跃函数**——
> 幅度差一点，结果就是 0 和 1 的区别。

---

## 4. 那怎么同时要两个能力

| 方案 | 说明 | 已验证 |
| --- | --- | --- |
| **多 LoRA 热挂载**（vLLM） | 一个基座 + 多个 adapter，按请求路由 | ✅ 之前测过：多 LoRA 比全量慢 42–57%，但能用 |
| 合并（TIES / DARE） | 剪枝 + 符号投票，比线性平均稳 | ⚠️ 未测，理论上对"冲突方向"更稳 |
| 训练一个多任务 LoRA | 数据混合，一次训完 | ✅ 最稳，但要重训 |
| 线性平均 | 本例 | ❌ 新能力会被平均掉 |

> **结论：想同时要多个能力，优先"多 adapter 路由"或"多任务混训"，
> 不要指望把两个 LoRA 平均一下。**

## 5. 复现

```bash
cd ~/apps/minimind
python merge_cross.py    # 训练 B（首次约 4 分钟）+ 扫 α
# 产物：out_cn_qwen/（B adapter）、merge_cross.json
```

### 5.1 两个坑（都踩了）

1. **复用同一个 base 对象加载多个 adapter** → LoRA 层被重复注入，全部 0%；
   必须每个配置重新 `from_pretrained`；
2. **B 的输出没有 EOS**，`generate` 会重复三遍；
   判据要取首行，否则 86.5% 会被判成 0%。

> 又是"判据 + 集成"吃掉结果的一天（本轮第 6、7 个）。

---

## 6. 结论

1. **跨能力合并也没能兼得**：50/50 时新能力（中文大写）**完全消失**；
2. **存在悬崖**：B 的权重 ≥75% 才能保住（85%），50% 就是 0%；
3. **原生能力的退化是温和的**：数学从 60% 降到 52%，因为基座本来就有 50%；
4. **新行为比增强脆弱**——合并平均的是偏置幅度，而输出格式是阶跃的；
5. **要组合能力，用多 adapter 路由或多任务混训，不要线性平均。**
